# ST-Capsule-Packer v2.0 — 酒馆单卡全内置打包器（多世界书 + 专属预设 + 删卡全清）

将角色卡绑定的**多本世界书（1 主 + N 附加 `extraBooks`）**、**专属 OpenAI 预设**与**正则**直接压缩内嵌进**单张标准角色卡（`.charx` / `.png`）的 `data.extensions`** 中。

## 核心特性（v2.0）
1. **单卡全内置（兼容酒馆原生「导入角色卡」按钮）**：
   - `.charx` 格式可直接通过微信无损传文件，在手机 Luker / SillyTavern 直接点自带的「导入角色卡」按钮即可导入高清封面与全部内置数据。
2. **强制统一最前端唯一前缀（如 `【AGY1128_01】`）**：
   - 角色卡、全部世界书、专属预设、正则统一使用同一个最前端前缀，窄屏一眼可见、列表自动聚拢，跨版本永不重名覆盖。
3. **自动挂接多世界书 + 切卡自动切换预设**：
   - 导入或首次打开卡片时自动写入全部内置世界书、刷新 `updateWorldInfoList()`、用精确无 `.png` 键名挂齐 `charLore.extraBooks`；
   - 点进该卡自动切换到它的专属预设，切去其他普通角色卡时自动恢复原本在用的常规预设。
4. **删卡即全家桶连根删除（监听 `CHARACTER_DELETED`）**：
   - 在酒馆里删除这张角色卡时，插件自动把同批次前缀的全部世界书与专属预设一并从磁盘删除，零垃圾残留；另附「🧹 前缀残留清理」面板可一键清理历史旧包。
