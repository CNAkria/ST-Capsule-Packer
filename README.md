# ST-Capsule-Packer（酒馆全量胶囊打包器）

适用于桌面端与移动端 **SillyTavern** 的全量角色备份与迁移扩展。支持将角色卡本体、激活预设、全局/局部/预设正则、酒馆助手脚本、绑定的多本世界书以及所有 `.jsonl` 历史聊天分支一键压缩打包进**单张标准角色卡 `.capsule.png`** 或独立的 **`.stcapsule.json`** 文件，并支持在任意设备上按需勾选一键还原。

## 安装方法（支持手机版与电脑版 SillyTavern）

打开 SillyTavern ➔ 顶部 **扩展 (Extensions)** ➔ **安装扩展 (Install extension)**，在扩展 Git URL 栏填入以下地址并点击安装：

```text
https://github.com/CNAkria/ST-Capsule-Packer
```

## 打开入口

- **手机端快捷入口**：点击聊天输入框左侧 `☰` 扩展魔棒菜单 ➔ **「全量角色胶囊打包 / 还原」**（针对手机竖屏触控与系统原生分享面板做了专门适配）
- **扩展抽屉入口**：顶部 `扩展` ➔ **「📦 酒馆全量胶囊打包器 (ST Capsule Packer)」**
- **角色编辑栏入口**：角色管理面板「导出」图标右侧的档案盒图标
- **斜杠命令**：发送 `/capsule`（导出）或 `/capsule import`（还原）

## 核心特性

- **单卡合一 `.capsule.png`**：完整保留标准 V2 (`chara`) 与 V3 (`ccv3`) 角色卡块，同时将多本世界书、预设、正则、酒馆助手脚本与全部聊天记录经 GZIP 压缩写入 PNG 的 `st_capsule` 块。
- **自动扫描绑定项**：自动识别主世界书、附加世界书 (`charLore.extraBooks`)、全局启用世界书、`WorldInfoLocks` 锁定书、人设世界书与聊天分支世界书，也可手动搜索多选任意其他世界书一并打包。
- **手机端一键分享转发**：在支持系统分享的手机浏览器上提供「📲 导出并系统分享」，可直接转发到微信、QQ、Telegram 或网盘发往电脑。
- **选择性无损还原**：拖入 `.capsule.png` 或 `.stcapsule.json`，自由勾选需要恢复的角色卡、世界书、预设、全局正则与聊天记录分支。
